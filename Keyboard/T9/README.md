# 九宫格（T9）应用层实现

设计全文见仓库根 `PLAN.md` 第 3 节。要点：

- **引擎只见字母**：数字序列在本层被切分为拼音音节，以 `'` 连接后整串喂 Rime 的
  雾凇拼音（rime_ice）会话；引擎侧不依赖 `t9_processor` 插件
  （雾凇自带 `t9.schema.yaml` 需要它，而 v1 选用的 LibrimeKit 二进制经实测不含该组件）。
- **映射表不手写**：`syllables.txt`（标准音节清单）+ 字母→数字规则在启动时生成
  `digitsToSyllables` 映射与前缀集合，生成法与 Hamster 的 T9Test 相同。
- **切分策略**：DP 求完整覆盖、音节数最少的最优切分；用户在音节条点选的音节
  以 `pinned` 锁定前缀，仅尾部重算。
- **删除**：弹掉最后一位数字 → 重新切分 → 重新喂入；Backspace 不透传引擎。
- **预编辑显示**：前端渲染「数字串 + 当前切分拼音」，不用引擎 raw preedit。
- **上屏后同步**：选中候选触发引擎部分上屏时，按候选 comment 反推已消耗的
  音节数，从数字串头部扣除对应位数（参照 Hamster `RimeContext` 的 T9 删除/同步处理）。
